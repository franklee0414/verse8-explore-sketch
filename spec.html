다크 톤의 커뮤니티형 탐색 화면을 화이트 톤의 스토어형 탐색 화면으로 전환하고, "제작 → 업로드 → 수익"의 흐름을 Explore 안에서 드러낸다. 기존 사이트 대비 바뀐 것, 뺀 것, 더한 것을 항목별로 이전 · 변경 · 의도로 정리했다.

3. 검색 신규

  • 돋보기 클릭 → GNB 입력창 확장 + GNB 아래로 흰 패널이 내려오고 뒤 페이지는 반투명 검정으로 어두워짐. 페이지 스크롤 위치는 보존.
  • 패널 상단: "실시간 인기검색" 칩 10개(순위 번호 없음). 클릭 시 해당 검색어로 즉시 결과 표시.
  • 입력 시: 패널 하단에 "'검색어' 검색 결과 · N개"와 7열 게임 카드 그리드. 결과 없음 안내 포함.
  • 닫기: × 버튼, Esc, 바깥 클릭, 돋보기 재클릭 중 어느 것이든 입력 · 패널 · 배경이 한 번에 닫힘.
  • 브라우저 기본 × 버튼은 숨겨 중복 표시 방지.

5. 본문 섹션

5.1 지금 주목할 게임 (이전 Featured)

  • 132px 정사각 썸네일 행. 왼쪽으로 70초에 한 바퀴 도는 무한 루프, 호버 시 정지.
  • 카드 정보는 게임명 + ★ 평점만 표시. 플레이 수 · 좋아요 · 크리에이터명 제거.
  • 호버: 이미지가 틀 안에서 10% 확대 (카드가 뜨는 효과 대신).

5.2 프로모 배너 (AI 제작 유도 → 수익 창출 유도)

  • 카피: "나만의 게임을 업로드하고, / 수익을 창출하세요!" · "프롬프트 한 줄, 차원이 다른 게임 제작 Tool을 경험하세요. / 수익 창출은 Verse8이 도와드립니다."
  • 버튼: "수익 창출하기" (동전 아이콘, Create와 같은 회전 그라데이션).
  • 우측 그래픽: Codex · V8 · Claude Code 앱 타일 3장이 겹쳐 선 구성. iOS 아이콘식 두께감(좌상단 하이라이트, 우하단 음영). V8 타일은 다크 아이콘, 글자는 90% 축소.
  • 수익 카드: "내 게임 수익 $1,840 ▲ 32%" + 막대 그래프. 4초 주기로 5.6px 떠오름. Claude Code 타일 위에 걸침.
  • 배경: Verse8 게임 아이콘 격자(투명도 22%, -6° 기울기, 왼쪽 페이드)가 페이지 스크롤의 40% 속도로 같은 방향으로 움직이는 패럴랙스. 세로 반복으로 가장자리 노출 없음.

5.3 IP Games (이전 Game Jams)

  • 섹션명 "IP Games", 부제 "게임잼 제출작 222개", 우측 링크 "게임잼 가이드".
  • 잼 타일 4개: 대표 게임 이미지 배경(투명도 80%). 진행 중 타일은 이미지를 더 밝게 하고 하단 그라데이션 위에 타이틀 · 기간, 흰색 "진행 중" 딱지. 마감 타일은 반투명 "마감" 딱지.
  • 제출작 행: 120px 썸네일(주목할 게임보다 10% 작게), 호버 시 좌우 화살표(히어로보다 20% 작게), 드래그 스크롤.

5.4 전체 게임 (이전 All Games)

  • 제목 줄 우측에 장르 · 정렬 드롭다운 2개. 장르 칩 행과 섹션 내 검색창은 제거.
  • 그리드: 한 줄 7개 × 4줄(28개), 가로 간격 22px(행 섹션과 동일), 정사각형 약 157px, 세로 간격 28px. 하단 "더보기".
  • 드롭다운: "장르" 접두어는 연회색 · 90% 크기, 선택값은 진하게. 열릴 때 화살표 180° 회전. 항목 호버 · 선택은 연회색 배경 + 검정 글자. 스크롤바 6px, 화살표 없음.
